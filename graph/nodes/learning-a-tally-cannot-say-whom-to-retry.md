21.09, первая рассылка «Что нового» трём живым пользователям прод-бота. Скрипт был сделан
аккуратно — id не печатаются, токен не печатается — и потому отдал только сводку:

    sent — HTTP codes: {403: 1, -1: 1, 200: 1}

Один получил, один отказал, у одного сеть. **Кто есть кто — неизвестно**, а повторить вслепую
значит прислать дубль тому, кто уже получил. Пришлось спрашивать Дениса, получил ли он сам, и
досылать двум оставшимся по его email-фильтру.

🔴 **Приватность вывода и адресуемость результата — не одно и то же.** Скрывать id правильно;
отказываться от адресации — ошибка. Результат пишется **по позиции или по хэшу id**: тогда он
не утекает и по нему можно повторить. Второй прогон так и сделан:
`#0 ru: 200 · #1 en: 403` — и сразу видно, что 403 у англоязычного оба раза.

**Где применить:** рассылка становится функцией вместе с кнопкой отписки (пункт C плана
`docs/superpowers/plans/2026-09-21-v04114-release-plan.md`) — журнал по получателю обязателен
с первого дня, а не после первого повтора.
