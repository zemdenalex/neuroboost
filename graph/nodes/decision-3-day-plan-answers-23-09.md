Запрос пришёл через корневую сессию: сделать NeuroBoost местом, где Денис и Настя ведут жизнь, за ~3 дня.
Порядок его: задачи без трения → проекты и подзадачи → дела и сферы вдвоём → деньги → Archifex (не здесь).

Ответы вариантами:
1. Строка без команды становится задачей сразу — **да** (собрано `c23bf67`, проверено им B1–B6 ✅, в проде с v0.4.11.4).
2. Сферы жизни — дословно: *«like tags inside one calendar, but it should be greater then just tags, like
   not the same, but we can start from tags then split it»*. Он сказал, что это обсуждалось раньше; в графе,
   `docs/` и `.remember/` проекта этого разговора не нашлось.
3. Деньги — **модуль долгов**.
4. Релизы — *«As always we discuss, when the version is clean it gets to the prod»*.

Бэклог оттуда же: MCP/API, чтобы ИИ-агенты клали задачи в его аккаунт (его мысль, не строить сейчас).
