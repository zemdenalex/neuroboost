## 3\. Календари — список и карточка

- [x] В списке видно все твои календари; личный подписан **· личный**, чужой — **· чужой**  
- [x] Нажатие на календарь открывает карточку: **Цвет · Участников · Роль**  
- [x] У личного календаря **нет** кнопок «Удалить» и «Выйти», но **есть** «Имя»  
- [x] У своего общего календаря есть всё: Имя · Цвет · Участники · Пригласить · Удалить

Во-первых должно быть не просто кнопка имя, а изменить название или название, имя это всё-таки у одушвленных, во-вторых в личный календарь нельзя приглашать сто процентов, надо вообще такое запретить

- [x] У чужого календаря есть только **Участники** и **Выйти** — ни Имя, ни Цвет, ни Пригласить

## 4\. Календари — действия

- [x] ➕ Создать → напиши имя → календарь появился в списке  
- [x] ✏️ Имя → напиши новое → имя поменялось  
- [x] 🎨 Цвет → выбери → в карточке новый цвет (и он же в вебе)  
- [x] 👥 Участники → список; у кого нет имени и email, показан как «—», а не «»  
- [x] 🗑 Удалить у **непустого** календаря → бот говорит, что сначала надо перенести события и задачи, и **не** делает вид, что удалил  
- [x] 🗑 Удалить у пустого → подтверждение **с именем календаря на кнопке** → удалился

## 5\. Приглашения — главное в релизе

- [x] 🔗 Пригласить → **🔗 Ссылкой** → бот прислал **одно готовое сообщение** со ссылкой `t.me/NeuroBoost_dev_bot?start=inv_…`  
- [x] Перешли это сообщение другому человеку (или открой со второго аккаунта)  
- [x] У него открывается бот и **сразу спрашивает «Принять?»** — не язык, не онбординг  
- [x] После «Принять» он в календаре, и **потом** идёт первая настройка, если он новый  
- [x] Вторая попытка по той же ссылке → бот честно говорит, что ссылка уже использована  
- [x] ✉️ По email на несуществующий адрес → бот предлагает дать ссылку, а не показывает ошибку
