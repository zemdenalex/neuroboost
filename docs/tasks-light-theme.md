# Задачи: светлая тема (по теме Telegram)

> Денис 25.09, страница вариантов https://claude.ai/artifact/GqNKUBaqERKbD6vFzJRyBD, выбор 3:
> **«B: follow Telegram's theme»** — у светлого Telegram светлое приложение.
> Веб сейчас только тёмный: 1529 классов `zinc-*` / `white` / `black` в 109 файлах `web/src` (посчитано 25.09).

## Подход (Ruling, обратимый)

Не переписывать 1529 классов. В `tailwind.config` палитра `zinc`, `white`, `black` задаётся через CSS-переменные
(`rgb(var(--nb-zinc-900) / <alpha-value>)`): в тёмной теме переменные дают сегодняшние цвета (ничего не
меняется), в светлой шкала переворачивается (950↔50, 900↔100, 800↔200 …, `white`↔почти чёрный,
`black`↔белый). Акценты (`blue`, `red`, `green`, `amber`) остаются. Потом проход по скриншотам и точечные
правки там, где переворот шкалы даёт плохой контраст. Цена ошибки: откат одного конфига.
