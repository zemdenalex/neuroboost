# План релизов v0.4.11.3 → v0.4.11.5

**Дата:** 18.09.2026 · **Решение Дениса 18.09 01:5x:** три релиза вместо одного.
**Первоисточник:** разговор 18.09 (быстрое добавление уже выпущено в v0.4.11.2; здесь — то,
что Настя и Денис нашли после).

## Почему режем именно так

Набралось **14 пунктов**. Спека связки аккаунтов одна оценивалась в «сессия с лишним на API +
полсессии веб + полсессии бот» — вместе получалось втрое больше, а документ на четырнадцать
пунктов не реализуют, его перечитывают.

🔴 **Граница не вкусовая, а деплойная.** Шесть пунктов не трогают `api-go` ни одним файлом.
Значит: нет миграции, нет мержа в `main`, нет бэкапа, нет прод-гейта — выкат руками на nl-2,
ровно как v0.4.11.1 и v0.4.11.2 (gotcha 19). Денис проверяет их на следующий день, а не после
прод-релиза.

| Релиз | Что | Чем выкатывается |
|---|---|---|
| **v0.4.11.3** — бот | карточки со всеми полями · календари в боте · приглашения ссылкой и по email · кнопки snooze под напоминанием · «сообщить об ошибке / предложить улучшение» · заметки о релизе | руками на nl-2, мержа нет |
| **v0.4.11.4** — API | повторяющиеся задачи · task↔event · частота напоминаний (долбёжка) · английский дайджест · язык кнопок под уведомлением · редактирование одного вхождения · API отвергает RRULE, который не разбирает | миграция + бэкап + мерж = **прод-релиз** |
| **v0.4.11.5** — связка | email ↔ Telegram, слияние аккаунтов | миграция + бэкап + мерж, **необратимо** |
