## 0. Три правила чтения этих документов

1. 🔴 **Статус работы — только `docs/ROADMAP.md`.** Все остальные документы либо старше, либо
   описывают свой кусок. ⚠ Но и у ROADMAP шапка врёт о собственной дате («Updated: 2026-07-19»
   при теле от 28.07).
2. 🔴 **Числа в документах протухли все до единого.** Не переносить их — пересчитывать:
   `ls api-go/migrations/*.up.sql | wc -l` · `git rev-list --count main..develop` ·
   `cd web && pnpm test --run`. См. §4.
3. 🔴 **`- [ ]` в `docs/superpowers/plans/` ничего не значит.** В трёх июньских планах все шаги
   пустые, а код собран целиком и местами новее плана. В одном апрельском плане текст PR с
   проставленными `- [x]` был написан ДО того, как прогнали хоть один тест.

## 7. Как этой картой пользоваться

- Паспорт в шапке каждого крупного документа (`<!-- паспорт: тип=… | статус=… | строк=… -->`)
  повторяет вердикт отсюда, чтобы он был виден **до** открытия файла.
  Пересчитать объём: `python E:/Projects/.claude/scripts/docs_passport.py "<корень>" --apply`.
  🔴 Статус в паспорте — поле человека: машина знает только путь и на каждом старом плане
  напишет «действует». Правь строку руками, перепрогон её сохранит.
- Текущее состояние работы (что открыто, чем заблокировано) живёт не здесь, а в `graph/` —
  индекс инжектится в каждую сессию. Эта карта отвечает только на вопрос «что за документ
  передо мной».
