## 1. Что входит — для людей

**Telegram Mini App**
- Кнопка «Календарь» слева от поля ввода в чате с ботом открывает NeuroBoost внутри Telegram, без входа
- Цвета твоей темы Telegram, «Назад» Telegram на внутренних экранах, ссылки на день и задачу (`?startapp=`)

**Веб на телефоне**
- Внизу три кнопки: Календарь · Добавить · Ещё
- День открывается на текущем часе, одна колонка, короткий заголовок
- «Месяц» на телефоне — выбор из трёх: месяц + список дня · полоса недели · тепловая карта
- Действия со строкой задачи: «⋯», свайп или карточка (выбор в настройках)
- «Что дальше»: тап по событию открывает его редактор; список до ~3 месяцев

**Что умеет бот — теперь и в вебе** (список дыр `docs/team/research/V003-20260926-res-bot-vs-web-gaps.md`)
- Одна строка как в боте: «стоматолог завтра 15:00 напомни за час» (тот же разборщик, `POST /api/parse`), «Отменить» после
- Главная = «Сегодня» бота: строка задач дня, события с–до, пять задач с галочкой
- Задачи дня: страница, квадраты в неделе и месяце, «📌 В задачи дня» у задачи
- Месячный вид на компьютере, пять вариантов
- Повторяющиеся задачи (включить, сменить, выключить), галочка закрывает только сегодня
- Задача ↔ событие: связать или перенести, по шагам, как в боте
- Запланировать: «когда» и «насколько» кнопками; срок и оценка в одно нажатие; подзадачи из меню
- Событие: весь день на несколько дней, «каждые N дней/недель», «каждый год»; правка больше не стирает «раз в 3 дня»
- Символ приоритета как в боте; «Свои слова» в настройках; повтор неотвеченного напоминания
- Светлая тема и выбор темы

**Бот**
- «ℹ️ Что в меню» на последнем экране настройки
- Язык бота — свой, отдельно от веба (решение Дениса 26.09)

**Прочее**
- Профиль и XP только из настоящих действий; Канбан, Эйзенхауэр, бюджет времени, планирование — правки из аудита 25.09

## 3. Как выпускаем — PR прямо из `develop`

11.6 собирали отдельной веткой из скопированных коммитов, и обратный мерж дал 18 конфликтов. В 12.0 уходит
**всё** с `develop`, поэтому ветка не нужна: PR `develop → main`. Мерж = прод (job `deploy`).

**В день релиза, по порядку:**
1. 🔴 До мержа: `ssh root@62.76.228.106 'cd /opt/neuroboost && git status --short && ls -la .dockerignore'` —
   ручных правок нет (26.09 чисто, кроме `.env.bak-2026-08-14`). Образ API теперь строится из корня: `.dockerignore` приедет с `git pull`
2. Запись «Что нового» v0.4.12.0 в `bot/internal/release/notes.go` с датой дня релиза (текст — §4)
3. Мерж PR → дождаться `deploy: success`, `https://neuroboost.website/api/health` 200
4. Прод-бот: строка `WEBAPP_URL=https://neuroboost.website` в `/opt/neuroboost-bot-prod/.env` (там `env_file: .env`) +
   выкладка `git archive` как в 11.6 → в логах «menu button opens https://neuroboost.website» и «Bot started»
5. Проверка на проде руками: кнопка «Календарь» в @NeuroBoost_assistant_bot открывает Mini App без входа
   (токен API = токен прод-бота, сверено хэшем 26.09 — вход по initData сработает)
6. Тег `v0.4.12.0`, мерж `main` обратно в `develop`, строка «Released» в `CLAUDE.md`
7. Денис: `/broadcast` в прод-боте

**Откат:** веб/API — `git revert` мержа на `main` (миграций нет, данные не меняются); бот — `src.bak-*` на nl-2.
