## 🔴 Что нашлось попутно

- **«каждый вторник» и «каждый год» из бота не повторялись никогда.** API разбирает только
  `FREQ=DAILY|WEEKLY|MONTHLY` с `INTERVAL/COUNT/UNTIL`; `BYDAY` и `YEARLY` он сохраняет, отвечает
  200 и показывает событие один раз. На проде таких событий ноль (проверено 17.09). Теперь бот
  пишет только то, что API разбирает, и тест это держит.
- **Бот жил в одном часовом поясе на всех** — `cfg.Timezone` контейнера. Теперь пояс
  каждого пользователя.
- **Парсер задач искал «завтра» подстрокой** — «купить завтрак» получала срок.
- **Текст, набранный вместо нажатия кнопки, стирал черновик** («Что-то пошло не так») — было
  и раньше, но онбординг теперь учит писать, а не нажимать. Нашёл независимый ревьюер; починено,
  черновик больше не теряется ни на одном экране.
