## Если пойдёт не так

- **API в crash-loop, `dirty = N`** — gotcha 18: доложить недостающее, затем
  `UPDATE schema_migrations SET version = N-1, dirty = false`, перезапустить.
- **Откат кода** — `main` вернуть на `3d1e152` (v0.4.11.2) и выкатить. ⚠ Миграции при этом
  **не откатываются сами**: схема 21 совместима с кодом 11.2 по всем добавленным колонкам
  (они nullable либо с DEFAULT), кроме `task.event_id` — её 11.2 не читает.
- **Бот** — вернуть `src.bak-<дата>` и пересобрать.

## Рассылка «что нового»

- **Кому:** `tg_id IS NOT NULL AND tg_auth_date > now() - 10 days` — по словам Дениса, «только
  тем, кто пользовался ботом в последние 10 дней». `tg_auth_date` обновляется на каждом
  Telegram-входе бота (`auth/handlers.go`, `updateTelegramInfo`).
- **Язык:** из `settings.bot.lang`. 🔴 Первый подсчёт я сделал по `settings.language` — ключа
  такого нет, `coalesce` превратил всех в русских, и получилось «0 англоязычных». На деле
  **1 en + 2 ru**: англоязычный получил бы сообщение по-русски. Проверка, которая не могла
  отказать.
- **Текст:** дословно заметки v0.4.11.3 — тот же источник, что экран «Что нового».
- **Как:** одноразовый скрипт на nl-2 (Telegram из РФ недоступен), id получателей идут по
  трубе из прод-базы и не попадают в транскрипт, токен читается из `.env` и не печатается.
- ⚠ **Кнопки «отписаться» пока нет** — Денис: *«в будущем надо будет сделать кнопку
  отписаться от обновлений, сейчас просто тестируем»*. До неё рассылка — разовое осознанное
  действие, не функция.

### ⚠ Рассылка — доставлена не всем

`recipients: 3 (ru 2, en 1)` → HTTP-коды **`200: 1 · 403: 1 · сеть: 1`**.

- **403** — Telegram отказал в доставке; обычно это «бот заблокирован пользователем».
  Повтор даст то же самое.
- **сеть** — исключение без HTTP-кода; текст ошибки не печатался намеренно (в нём может быть
  URL с токеном). Скорее всего разовый таймаут.
- 🔴 **Кто именно не получил — неизвестно**, и это моя недоработка скрипта: он отдавал
  сводку кодов, а не результат по позиции. Повторить вслепую = прислать дубль тому, кто уже
  получил. `getChat` после этого вернул 200 для всех трёх — адреса живые.
- Решение за Денисом: он сам один из троих.

**Дослано 21.09, 19:05** — Денис подтвердил, что получил сам; двоим остальным (фильтр по его
email дал ровно 2 из 3 — проверено до отправки), с результатом по позиции:
`#0 ru: 200` · `#1 en: 403`. Итог: **2 из 3 доставлено**; англоязычный получатель дал 403 оба
раза — это его сторона (обычно блокировка бота), досылать нечем.

Урок для будущей кнопки «отписаться» и любой рассылки: **результат записывается по
получателю** (по хэшу id, не по самому id), иначе повтор невозможен без дублей.
