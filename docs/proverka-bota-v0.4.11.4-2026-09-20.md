клали правило в базу **прямым INSERT'ом, минуя API**. Поэтому всё было зелёным, а фичи не
существовало. Версия на dev при этом была правильная.

## 1. 📊 Статистика — не трогал, твои замечания в очереди

Два твоих вопроса, на которые нужен ответ до переделки:

- [ ] «Занято: N ч» — сейчас это **сумма длительностей событий**, и два события на одно и то же

- [ ] Чёрные квадраты столбиков (`▪`) — заменить на что? Предложу `▁▂▃▄▅▆▇` высотой по числу,

## 2. Повторяющиеся задачи — переделано, проверять заново

🟢 Починено: парсер, карточка, мастер, отправка в API, приём в API.

- [ ] Напиши `пить таблетки каждый день` → на карточке строка **🔁 Повтор: каждый день**,
      а в названии осталось только «пить таблетки»
- [ ] То же для `ежедневно пить таблетки`, `полить цветы через день`, `отчёт каждую неделю`,
      `раз в 3 дня протереть пыль`
- [ ] 🔴 Твоя фраза дословно: `задача повтор пить таблетки` → название «пить таблетки»,
      а вместо строки повтора — **«⚠ повтор — частота не указана, спрошу»**
- [ ] `купить молоко` (без повтора) → строка **🔁 Повтор: нет**
- [ ] `отжаться 12 раз` → это двенадцать отжиманий, **не** серия из двенадцати
- [ ] Английский: `take pills every day` понимается так же

**Мастер:**

- [ ] «📝 Подробнее» → приоритет → срок → **Повторять?** → оценка
- [ ] На шаге «Повторять?» есть кнопки: Каждый день · Через день · Каждую неделю ·
      Каждый месяц · **Не повторять**
- [ ] 🔴 Твой вопрос «почему здесь нет своего варианта»: на шаге **«Сколько времени займёт?»**
      напиши **`5м`** — принимает, а не «Здесь нужна кнопка»
- [ ] На шаге «Повторять?» напиши **`раз в 3 дня`** — принимает
- [ ] Напиши туда чепуху (`быстро`) → бот говорит, что понимает, и **черновик не теряется**

**Что реально создалось:**

- [ ] Созданная повторяющейся задача открывается (📋 Задачи → нажми на неё) и в карточке
      написано **🔁 Повторяется**
- [ ] У неё кнопка называется **«✅ На сегодня»**, а не «Готово»
- [ ] 🔴 Нажми её → «Сделано на сегодня» → задача **ушла из списка**, а внизу появилась
      строка **«✅ сегодня: 1»**
- [ ] Завтра (или сдвинь часовой пояс в ⚙️ Настройки) она **снова в списке**
- [ ] У обычной задачи кнопка по-прежнему «✅ Готово» и закрывает её насовсем

⚠ **Чего в этом разделе всё ещё нет** — не ищи: выключить повтор у **уже созданной** задачи из
бота нельзя (API умеет, кнопки нет). Скажи, нужна ли в этот релиз.
