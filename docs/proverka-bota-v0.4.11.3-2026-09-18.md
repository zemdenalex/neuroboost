## 1. Карточка называет все поля

- [ ] Напиши `стоматолог завтра 15:00`. На карточке есть строки: **Повтор · Календарь ·
      Напомнить · Теги · Цвет**, и у пустых написано **«нет»**
- [ ] «Напомнить» у нового события говорит **«как обычно»**, а не «нет» — это разные вещи
      («как обычно» = сервер поставит твой пресет, «не напоминать» = молчать всегда)
- [ ] Выбери «не напоминать» — строка меняется на **🔕 Напомнить: не напоминать**
- [ ] Напиши `оркестр среда 14:00-15:00 каждую неделю синий #музыка` — заполненные поля
      печатают значения, а не «нет»
- [ ] Переключи язык на английский (⚙️ → 🌐) — те же строки называются
      **Repeat / Calendar / Remind / Tags / Colour**, пустые — **none**
- [ ] Карточка задачи (`задача на завтра доделать сайт`) тоже называет все поля
- [ ] **Заметка**: на карточке есть строка «📝 Заметка: нет»; ✏️ Изменить → Заметка →
      напиши длинный текст → на карточке видно начало и **многоточие**, а не весь текст
- [ ] Создай событие с заметкой → открой его в вебе → заметка там **целиком**, не обрезана
- [ ] Отредактируй у этого события время в боте → заметка **не пропала**

## 2. Календари — вход

- [ ] 🗓 Календарь → внизу месяца есть кнопка **📁 Календари**
- [ ] ⚙️ Настройки → там же есть **📁 Календари** (второй вход, как просил)
- [ ] Обе кнопки открывают **один и тот же** экран

## 3. Календари — список и карточка

- [ ] В списке видно все твои календари; личный подписан **· личный**, чужой — **· чужой**
- [ ] Нажатие на календарь открывает карточку: **Цвет · Участников · Роль**
- [ ] У личного календаря **нет** кнопок «Удалить» и «Выйти», но **есть** «Имя»
- [ ] У своего общего календаря есть всё: Имя · Цвет · Участники · Пригласить · Удалить
- [ ] У чужого календаря есть только **Участники** и **Выйти** — ни Имя, ни Цвет, ни Пригласить

## 4. Календари — действия

- [ ] ➕ Создать → напиши имя → календарь появился в списке
- [ ] ✏️ Имя → напиши новое → имя поменялось
- [ ] 🎨 Цвет → выбери → в карточке новый цвет (и он же в вебе)
- [ ] 👥 Участники → список; у кого нет имени и email, показан как «—», а не «<nil>»
- [ ] 🗑 Удалить у **непустого** календаря → бот говорит, что сначала надо перенести
      события и задачи, и **не** делает вид, что удалил
- [ ] 🗑 Удалить у пустого → подтверждение **с именем календаря на кнопке** → удалился

## 5. Приглашения — главное в релизе

- [ ] 🔗 Пригласить → **🔗 Ссылкой** → бот прислал **одно готовое сообщение** со ссылкой
      `t.me/NeuroBoost_dev_bot?start=inv_…`
- [ ] Перешли это сообщение другому человеку (или открой со второго аккаунта)
- [ ] У него открывается бот и **сразу спрашивает «Принять?»** — не язык, не онбординг
- [ ] После «Принять» он в календаре, и **потом** идёт первая настройка, если он новый
- [ ] Вторая попытка по той же ссылке → бот честно говорит, что ссылка уже использована
- [ ] ✉️ По email на несуществующий адрес → бот предлагает дать ссылку, а не показывает ошибку

## 6. Отложить напоминание

- [ ] Дождись напоминания (или заведи событие через 2 минуты с напоминанием «за 1 мин»)
- [ ] Под ним **три** кнопки: ✅/👌 · ⏰ 10 мин · ⏰ Час
- [ ] «⏰ Час» действительно откладывает на час, а не на 10 минут
- [ ] ⚠ Кнопки по-прежнему по-русски даже в английском режиме — **это известно и чинится
      в v0.4.11.4**, отмечать дефектом не надо

- [ ] Обращения видно в админке на сайте (`/admin`), тип — bug / feature
