### Правила, нарушение которых дороже пропущенной задачи

1. 🔴 **Мерж `develop` → `main` = РЕЛИЗ ПРОДА.** Сам не мержу и не пушу в `main` **никогда**.
   Дохожу до готовности и **спрашиваю Дениса явным вопросом**.
2. 🔴 **Не убирать работающую возможность ради более простой.** Новое — рядом со старым.
   (`preference-never-replace-a-working-capability-with-a-simpler-one`; нарушено 15.08 с
   выбором цвета.)
3. 🔴 **Контроль, который не мог отказать, — не подтверждение.** После каждой починки
   **саботировать охраняемое** и убедиться, что тест краснеет. Не покраснел — это не тест.
4. 🔴 **Не пушить, пока Денис проходит staging руками** — push пересобирает staging под ним.
5. Проверка до «готово»: `cd api-go && go build ./... && go vet ./... && go test ./...` ·
   то же в `bot` (**отдельный модуль**) · `cd web && corepack pnpm typecheck && corepack pnpm
   lint && corepack pnpm test --run && corepack pnpm build`.
6. `git add` конкретных файлов, никогда `-A`, никогда со-автор Claude/Anthropic. Сообщение
   коммита — **через файл** (`git commit -F`), иначе bash съедает обратные кавычки.
7. Числа не переносить — пересчитывать.

### Очередь работ, по убыванию ценности

**A. Добить обещанное Денису**
1. **Пресеты напоминаний: добавить / переименовать / удалить.** Сейчас три зашитых, управления
   нет. Хранятся в `settings.reminders.presets` (JSONB) — миграция не нужна.
   ⚠ `matchPreset` возвращает **первое** совпадение: запретить одинаковые имена и предупреждать
   о совпадающих наборах, иначе селект снова начнёт «отскакивать» (дефект 14.08).
   🔴 Редактор пресета не должен содержать выбор пресета — `showPresetPicker={false}`.
2. **Фильтр видимости календарей на `/calendar`** плюс правка календаря там же. Список сейчас
   живёт только в `/settings`. Цвета уже есть (`lib/calendar/palette.ts`).
3. **Перенос события между календарями**: `PATCH /api/events/:id` не принимает `calendar_id`.
   Проверять доступ **тем же** `calendars.WritableIDFor` — и к старому, и к новому календарю.
4. **Русские имена в данных**: `Мой календарь` (миграция `000012` + `store.go:82`), имена
   пресетов. Сделать переводимыми ключами, не литералами.

⚠ **Приглашения (шаринг) — НЕ в этой очереди.** Это срез 3 спеки P3: миграция, ручки, UI.
Отдельная работа, начинать только по явной просьбе Дениса.
