## Приоритет проверки — по риску

### 🔴 1. Onboarding и contextual help (никогда не открывались в браузере)

Самая большая новая фича, покрыта только unit-тестами чистых функций. React-компонентного
harness в проекте нет.

- [ ] Первый вход: видна welcome-карточка с циклом capture → schedule → do → reflect
- [ ] Guided checklist: отмечается сам по мере создания task/event/reflection, исчезает по завершении
- [ ] Кнопка «?» на **каждой** странице (Calendar, Tasks, Planning, Reflections, Tools, Settings)
- [ ] «Показать подсказки» в Settings — все **3 стиля**: bubbles / walkthrough (spotlight) / markers
- [ ] Guided empty states: пустой Planning и пустой Dashboard
- [ ] Переключить язык **en ↔ ru** — подсказки и checklist переведены полностью
- [ ] Сбросить onboarding (localStorage) и пройти заново — состояние не залипает

### 🔴 2. Pomodoro (тоже только unit-тесты)

- [ ] Запустить таймер, **уйти на другую страницу** — плавающий виджет живёт и продолжает счёт
- [ ] Три стиля виджета: pill / card / bar
- [ ] Дождаться перехода фазы — звук + уведомление срабатывают **один раз**, не дублируются
- [ ] Цикл-pips отражают реальную позицию в цикле
- [ ] По завершении — toast с **Undo**; проверить, что Undo действительно откатывает
- [ ] Время пишется в задачу (`actual_minutes`) — видно в задаче после завершения
- [ ] **Перезагрузить страницу с активным таймером** — восстанавливается по timestamp, не сбрасывается

### 🟠 3. Регрессии в том, чем пользуешься каждый день

- [ ] Календарь: создать / подвинуть / растянуть событие (одиночное, в пределах дня)
- [ ] Перетащить задачу из sidebar на календарь → создаётся событие, статус SCHEDULED
- [ ] Recurring: событие с повтором **отображается** корректно
      ⚠️ **Редактировать/двигать recurring не пробуй — вернёт 500.** Это известный R1, чинится
      отдельно; delete одного вхождения уже починен, но фронт ещё не шлёт `scope`.
- [ ] Неделя листается вперёд/назад, «Today» возвращает на текущую
- [ ] Export → Import: выгрузить, загрузить обратно, данные не потерялись и не задвоились
- [ ] Мобильный размер (375px): шапка не наезжает, editor не переполняется, FAB не перекрывает feedback

### 🟡 4. Мелочи, которые чинились в этом релизе

- [ ] Due-date у задачи не съезжает на день при редактировании
- [ ] Даты и дни недели на выбранном языке (не хардкод ru/en)
- [ ] Profile: таймзона принимает любую IANA-зону
- [ ] Пересекающиеся события лежат рядом в колонках, а не друг на друге

## Известные баги — НЕ считать регрессией

| Что | Почему |
|---|---|
