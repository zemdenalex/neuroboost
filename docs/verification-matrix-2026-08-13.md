## Как прогнать всё — один блок

```bash
# 0. База — без неё 15 Go-тестов ПРОПУСКАЮТСЯ МОЛЧА и прогон выглядит полным
docker compose up -d db
export DATABASE_URL="postgres://neuroboost:<пароль из .env>@localhost:5432/neuroboost?sslmode=disable"

# 1. Go — ДВА модуля, две команды. `go build ./...` из api-go в bot/ НЕ заходит
cd api-go && go build ./... && go vet ./... && go test ./...
cd ../bot && go build ./... && go vet ./... && go test ./...

# 2. Фронт — все четыре. С 13.08 добавился lint: typecheck его не заменяет,
#    `any` типобезопасен по определению и tsc про него молчит
cd ../web
corepack pnpm typecheck
corepack pnpm lint
corepack pnpm test --run
corepack pnpm build

# 3. e2e — против ЗАДЕПЛОЕННОГО staging, не против dev-сервера.
#    С 13.08 это делает CI сам, после deploy-dev. Руками:
export E2E_TG_BOT_TOKEN="<TELEGRAM_BOT_TOKEN dev-API>"   # тот же, что у API, иначе HMAC не сойдётся
export E2E_TG_ID="<числовой telegram id>"
corepack pnpm e2e
```

## Что не покрыто ничем — список, а не пустые клетки

1. 🔴 **Три инструмента**: kanban, eisenhower, time-blocking — ни unit, ни e2e, ни ручного прохода.
2. 🔴 **`feedback` и `admin` на бэкенде** — ноль тестов, при том что `feedback` **публичная**
   ручка без JWT.
3. 🔴 **`Settings.tsx` целиком** — 13 секций, покрыты только отдельные хелперы. Здесь же живёт
   подтверждённый дефект: cleanup на unmount обещает комментарием flush, а делает `clearTimeout`,
   и правка + уход внутри 300 мс теряется молча.
4. 🔴 **Мобильный вьюпорт для drag/resize** — обе спеки на 375px пропускаются.
5. 🔴 **Флоу события в боте** — 11 unit-тестов разбора строки, ноль проверок человеком.
6. 🟡 **Импорт большого файла** — новый лимит 32 MiB не проверен настоящим экспортом.

## Контроли, которые не могли отказать

**Починено 13.08:**
- ✅ **e2e не запускались ни одним job** — 10 спек лежали мёртвым грузом, а `CLAUDE.md` цитировал
  три из них как доказательство закрытых MD1/MD2. Теперь job `e2e` после `deploy-dev`, и он
  **падает громко** без `E2E_TG_BOT_TOKEN`/`E2E_TG_ID`: без них фикстура пропускает все
  аутентифицированные спеки и «зелено» не значило бы ничего.
- ✅ **ESLint отсутствовал полностью** при запрете `any` в трёх файлах правил. Добавлен, доведён
  до 0 errors, **проверен намеренным `any`** — краснеет.
- ✅ **`BodyLimit`** — новый контроль, сразу проверен саботажем: замена строки
  `http.MaxBytesReader` на пустышку роняет `TestBodyLimitRejectsOversizedBody`.
- ✅ **Посев локали в `localStorage` не мог сработать никогда.** Спеки адресовали контролы по
  переводимым именам («Edit Task»), а `AuthContext` берёт `locale` из профиля пользователя и
  перекрывает им посеянное; колонка по умолчанию `'ru'`. Строка выглядела как настройка языка и
  ею не была. **Обнаружено первым же прогоном e2e-job'а в CI** — до этого спеки не запускались,
  и дефект был невидим. Починено в фикстуре: `PATCH /api/auth/me` с `locale: 'en'`, с громким
  падением, если запрос не прошёл.

  🔴 **Это второй случай той же ловушки за сутки** (первый — вариант раскладки, посеянный в
  `localStorage` и перезаписанный настройками с сервера). Правило: **посев в `localStorage`
  проигрывает всему, что приходит с сервера при монтировании.**

**Открыто:**
- 🔴 **`minSQLBlocksScanned = 68` при фактических 76** (`calendars/scoping_test.go:60`) —
  архитектурный tripwire потерял 8 запросов зазора вопреки собственному комментарию. Он
  сработает не тогда, когда задумано.
- 🔴 **15 Go-тестов пропускаются без `DATABASE_URL`.** В CI база есть, локально её обычно нет —
  значит локальное «всё зелено» слабее CI-шного, и это надо помнить, а не открывать заново.
- 🟡 **`web/pnpm-lock.yaml` в `.gitignore`** (`.gitignore:104`) — CI ставит зависимости без
  lockfile, версии в CI не обязаны совпадать с локальными.
- 🟡 **Версия в `/api/health` захардкожена** `"0.4.0"` (`status/handlers.go:44`) — по ней нельзя
  понять, какой билд выкачен. Судить по поведению, не по строке.
