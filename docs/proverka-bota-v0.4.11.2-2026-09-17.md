## Что нашлось попутно

- 🔴 **«каждый вторник» и «каждый год» из бота не повторялись никогда.** Бот писал
  `FREQ=WEEKLY;BYDAY=TU` и `FREQ=YEARLY`, а API понимает только DAILY/WEEKLY/MONTHLY с
  INTERVAL/COUNT/UNTIL (`api-go/internal/events/recurrence.go`). Непонятное правило API не
  отвергает: событие показывается один раз. На проде таких событий **ноль** (проверено
  запросом 17.09), так что вред не случился. Теперь бот пишет `FREQ=WEEKLY` от вторника и
  `FREQ=MONTHLY;INTERVAL=12`; тест держит, что каждое правило бота разбирается API.
- 🔴 **Бот жил в одном часовом поясе на всех** — `cfg.Timezone` контейнера. Теперь пояс
  берётся из аккаунта каждого пользователя.
- ⚠ **Парсер задач искал «завтра» подстрокой** — «купить завтрак» получала срок на завтра.
  Тот же дефект, что когда-то дал событие «к»; в парсере событий его починили раньше, в задачах
  он дожил. Теперь по словам.
