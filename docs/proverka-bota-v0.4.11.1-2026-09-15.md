## A. Твой пример, дословно (пункт 1)

`➕ Создать` → `Событие`, затем:

- [ ] **A1.** `среда 14:00-15:00 оркестр повтор`
  Ожидается: карточка с названием **оркестр**, датой **среда, 16 сентября**,
  временем **14:00–15:00**, строкой **⚠ повтор — частота не указана, спрошу**.
  🔴 Слова «среда», «повтор» в названии быть не должно.
- [ ] **A2.** Нажать **✅ Подтвердить** → должен спросить частоту кнопками,
  а не создать разовое событие.
- [ ] **A3.** Выбрать «Каждую неделю» → вернуться на карточку, там **🔁 каждую неделю**.
- [ ] **A4.** Ещё раз **✅** → событие создано. Проверить на сайте, что повтор стоит.

## B. Дни недели и время (пункт 1)

- [ ] **B1.** `оркестр следующая среда 14:00` → **23 сентября**.
- [ ] **B2.** `оркестр вторник 20:00` → **сегодня, 15 сентября** (ближайший = включая сегодня).
- [ ] **B3.** `созвон в пятницу 10:00` → **18 сентября**, название **созвон** (без «в»).
- [ ] **B4.** `планёрка пн 09:00` → **21 сентября**.
- [ ] **B5.** `call wednesday 11:00` → **16 сентября**.
- [ ] **B6.** `обед полдень завтра` → **16 сентября, 12:00**.
- [ ] **B7.** 🔴 **Тот самый баг:** `10:00 завтрак` → название **завтрак** (не «к»),
  дата **не указана** (спросит). Раньше было «к» и завтрашний день.
- [ ] **B8.** `ужин втроём завтра 19:00` → название **ужин втроём** целиком.
  «вт» внутри «втроём» не должно стать вторником.

## C. Кнопка меню прекращает создание (пункт 2)

- [ ] **C1.** Начать создание события, **не отвечая** нажать `🗓 Календарь`
  на нижней клавиатуре → открывается календарь, создание прекращено.
- [ ] **C2.** Сразу после этого написать что-нибудь → бот отвечает меню,
  а не создаёт событие с этим названием.
- [ ] **C3.** Повторить с `📋 Задачи` и `⚙️ Настройки`.

## D. Ключевые слова и карточка (пункт 3)

- [ ] **D1.** `анализы весь день четверг` → **весь день**, 17 сентября, название **анализы**.
- [ ] **D2.** `созвон синий завтра 10:00` → 🎨 **синий**. Проверить на сайте, что событие синее.
- [ ] **D3.** `отжаться задача завтра 10:00` → карточка помечена ✅, после создания
  есть и задача, и событие, связанные.
- [ ] **D4.** `созвон работа завтра 10:00` (если календарь «Работа» есть) → 📁 **Работа**.
      Если нет — слово должно остаться в названии, а не пропасть.
- [ ] **D5.** `оркестр #музыка #дела завтра 14:00` → 🏷 **музыка, дела**.
- [ ] **D6.** 🔴 **Изменить → Название**, написать `весь день повтор синий` →
      название должно стать **ровно этой строкой**, ключевые слова не действуют.
- [ ] **D7.** 🔴 **Изменить → Теги**, написать `полдень, среда` → тегами становятся
      **полдень** и **среда**, временем и датой они НЕ становятся.
- [ ] **D8.** **Изменить → Весь день** переключает туда и обратно.
- [ ] **D9.** **🗑 Отменить** на любом шаге закрывает создание без следа.

## E. Напоминания (пункт 4)

- [ ] **E1.** `созвон завтра 10:00 напомнить за 15м` → 🔔 **за 15 мин.**
- [ ] **E2.** **Изменить → Напоминания → «Не напоминать»** → 🔕 **не напоминать**.
- [ ] **E3.** **Изменить → Напоминания → «По умолчанию»** → строки про напоминание
      на карточке нет вовсе (сервер применит твой пресет).
      ⚠ E2 и E3 обязаны выглядеть по-разному. Если одинаково — это дефект.

## F. Списки (пункт 5)

- [ ] **F1.** Создать задачу, отправить:
  ```
  1. Отжаться
  2. Подтянуться
  3. Присесть
  ```
  → спрашивает «одна запись или список из 3».
- [ ] **F2.** Выбрать «Список из 3» → три записи, пронумерованы.
- [ ] **F3.** 🔴 **Твой блок событий:**
  ```
  среда
  10:00 завтрак
  12:00-14:00 оркестр
  17:00 работа
  четверг
  8:00 анализы
  ```
  → **четыре** события: завтрак / оркестр / работа на **16.09**, анализы на **17.09**.
  Строки «среда» и «четверг» отдельными событиями быть не должны.
- [ ] **F4.** **✏️ Изменить** → выбрать строку 2 → поправить время → **⬅️ К списку** →
      изменение видно в списке.
- [ ] **F5.** **✅ Создать 4** → перечисляет созданные по именам.
- [ ] **F6.** `Ужин, завтра 19:00` → это **одна** запись, вопроса быть не должно.
