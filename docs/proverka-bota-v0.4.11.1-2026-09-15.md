## A. Твоё расписание целиком — главная проверка

Отправь блок из своего сообщения дословно (`Вторник:` … `Сб и вс пока хз`), выбери
**«Список»**. Ожидается:

- [ ] **A1.** Порядок в каждой строке: **🗓 дата · 🕐 время · 📅 название**. Не наоборот.
- [ ] **A2.** `10:40-12 спец` → **10:40–12:00**, название «спец».
- [ ] **A3.** `12:00 -12:50 физра` → **12:00–12:50**, название «физра» (раньше было «12:50 физра»).
- [ ] **A4.** `13;00 обед` → **13:00**, название «обед».
- [ ] **A5.** `12:00 -14:40 обед, сон или на скрипке буду играть` → **12:00–14:40**,
      название без времени в начале.
- [ ] **A6.** Строки, где время понято нестрого, помечены **⚠ проверь**. Строгие — не помечены.
- [ ] **A7.** Дни наследуются: вторник → среда → четверг → пятница → суббота.

## I. Свои слова как триггеры (пункт 4 второго списка)

- [ ] **I1.** `⚙️ Настройки` → `🔤 Ключевые слова` → `➕ Добавить` → слово `созвон` →
      кнопка **📁 Календарь** → написать `Работа`.
- [ ] **I2.** `созвон завтра 10:00` → 📁 **Работа**, название «созвон» пропало из текста.
- [ ] **I3.** Добавить слово с типом **🎨 Цвет** → выбрать кнопкой → слово красит событие.
- [ ] **I4.** Добавить слово с типом **🗓 Дата** → значение `завтра` → слово ставит завтра.
      ⚠ Хранится фраза, не дата: через неделю «завтра» останется завтрашним днём.
- [ ] **I5.** Типы **🌅 Весь день** и **✅ Задача** значения не спрашивают.
- [ ] **I6.** 🔴 Добавить `синий` как **🏷 Тег** → затем `созвон синий завтра 10:00`
      должно остаться **цветом**. Встроенное значение сильнее своего слова.
- [ ] **I7.** 🔴 После всего этого открыть `🕘 Рабочие часы` — они **на месте**.
      Если пропали — это gotcha 21 и блокер.
- [ ] **I8.** Удалить слово кнопкой 🗑 → исчезает, остальные остаются.

## K. Язык интерфейса

- [ ] **K1.** `⚙️ Настройки` → `🌐 Язык` → **English** → весь бот отвечает по-английски:
      меню, карточка, гайды, кнопки, ошибки.
- [ ] **K2.** 🔴 Сразу после переключения нажми **старую** кнопку нижней клавиатуры
      (она ещё русская, пока не пришла новая) — должна работать. Клавиатура живёт на
      телефоне, а не на сервере.
- [ ] **K3.** На английском создай событие: `среда 14:00-15:00 оркестр повтор` —
      слова распознавания работают **на обоих языках всегда**, от настройки не зависят.
- [ ] **K4.** Вернуть **Русский** → всё обратно.
- [ ] **K5.** 🔴 Проверить, что рабочие часы и ключевые слова **на месте** после
      переключения туда-обратно. Язык лежит в том же blob (gotcha 21).
- [ ] **K6.** ⚠ Кнопки под **уведомлением** («✅ Готово», «⏰ +10 мин») остаются русскими
      в любом случае — это известный пробел, причина в коде: уведомления шлёт notifier,
      который не знает, кому пишет, кроме telegram id.
