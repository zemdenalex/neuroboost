## 🔴 Главное, ради чего этот файл существует: без базы 15 тестов пропускаются молча

```
с    DATABASE_URL → 167 PASS,  0 SKIP
без  DATABASE_URL →            15 SKIP   ← и прогон всё равно «зелёный»
```

Тесты, работающие с базой, зовут `t.Skip`, когда `DATABASE_URL` не задан. CI переменную задаёт,
локальный прогон — нет. Именно так 11.08 двенадцать зелёных локальных прогонов подряд не
заметили nil pointer, который CI уронил с первого же push.

🔴 **Правило:** трогаешь код, покрытый тестами с базой, — поднимай базу локально **до** push:

```bash
docker run --rm -d --name nb-test-pg -e POSTGRES_PASSWORD=x -p 5433:5432 postgres:16
migrate -path api-go/migrations \
  -database "postgres://postgres:x@localhost:5433/postgres?sslmode=disable" up
cd api-go && DATABASE_URL="postgres://postgres:x@localhost:5433/postgres?sslmode=disable" \
  go test -count=1 ./...
docker rm -f nb-test-pg
```

Если в выводе есть `SKIP` — переменная не доехала до процесса. Это повод разбираться, **а не
«тесты зелёные»**.

### Go `api-go` — 167 прошло, 7 пакетов

`auth` · `calendars` · `events` · `export` · `reminders` · `tasks` · `usersettings`.
Миграций накатано **12**, `migrate version` = 12.

Внутри `calendars` живут два **архитектурных охранных теста** (`scoping_test.go`): они читают
исходники пакета и валят сборку, если запрос к таблицам `event`/`task` ограничен по `user_id`
или если `INSERT` в них не задаёт `calendar_id`. У них есть «пол» `minSQLBlocksScanned = 68`
при фактических 76 — тест, нашедший подозрительно мало SQL-блоков, падает вместо того, чтобы
молча позеленеть.

### Go `bot` — 20 прошло, 3 пакета

`internal/api` · `internal/auth` · `internal/notifier`.

🔴 **Это отдельный Go-модуль.** `go build ./...` из `api-go` сюда не заходит, поэтому сломанный

### Фронт — 358 юнитов, 42 файла

В проекте **нет `@testing-library`**, поэтому компоненты юнит-тестами не покрываются вовсе:
проверяемая логика выносится чистой функцией в `web/src/lib/` и тестируется там, а поведение
UI покрывает e2e.

🔴 **`typecheck` — настоящий гейт, не `build`.** Vite стирает типы, поэтому `build` проходит на
коде с ошибкой типов. За эти сутки `typecheck` дважды поймал то, что `build` пропустил бы
(сломанная JSX-вложенность в `Admin.tsx` — комментарий `{/* */}` сразу после `&& (`).

### e2e — 26 прошло, 4 пропущено

10 спек × 2 проекта (`desktop` 1440×900, `mobile` 375×667), против **задеплоенного** staging,
а не против локальной сборки.

**Пропускаются четыре — и это ожидаемо, а не сбой:** мобильные варианты drag-спек
(`crossday-resize`, `multiday-resize`, `drag-commit-repaint`, `move-grab-offset`). На 375px
календарь показывает один день, второй колонки на экране нет, тянуть событие через сутки
физически некуда.

⚠️ Базовая линия **26/4**. Любое отклонение — регресс, а не флак: спеки гоняются против общего
staging и уже ловили настоящие поломки (две мобильные спеки упали во вторник без единой правки
кода, потому что базовую линию сняли в понедельник).
