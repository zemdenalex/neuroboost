# A1 · задача ↔ событие, API — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `api-go` умеет превратить задачу в событие и событие в задачу — с повтором `series|once`,
в часовом поясе пользователя, одной транзакцией, — а быстрый «⏰ Запланировать» идёт тем же путём.

**Architecture:** задача → событие остаётся в пакете `tasks` (`convert.go`); общая вставка связанного
события (`insertLinkedEvent`) используется и `Convert`, и `scheduleTask`. Событие → задача — новый
файл в пакете `events` (`totask.go`): там живёт всё, что нужно для вхождений серии (`parseInstanceID`,
`occurrenceWindow`, exceptions). Импорт `tasks ↔ events` не появляется ни в одну сторону. Карточку
«что чем станет» для события бот строит из ответа `dry_run` — отображение полей живёт в одном месте,
в API.

**Tech Stack:** Go 1.22, chi, pgx/v5, PostgreSQL 16. Модуль `api-go/` (бот — отдельный модуль, в A1 не трогается).

**Spec:** `docs/superpowers/specs/2026-09-21-v04114-bot-design.md` §A1 (утверждена 21.09).

## Global Constraints

- 🔴 **Ни одной миграции.** Понадобилась — остановиться и спросить Дениса: 11.4 обещан релизом «только кодом».
- 🔴 Каждый новый `INSERT` в `event`/`task` — в функции, которая зовёт `calendars.WritableIDFor`
  (единственное число); `UPDATE`/`DELETE` — `calendars.WritableIDsFor`. Иначе краснеет
  `calendars.TestWritesScopeByWritableCalendars`. Множественное число ограничивает `WHERE`, но не
  разрешает запись в конкретный календарь.
- 🔴 Одна конверсия = одна транзакция. Полупереход хуже любого исхода.
- 🔴 Всё, что называет день, — **дата в зоне пользователя** (`COALESCE(u.timezone,'Europe/Moscow')`),
  не момент и не зона сервера.
- DB-тесты: `DATABASE_URL=postgres://…@localhost:55432/… go test -count=1 ./...`. Без `DATABASE_URL`
  тест скипается и печатает `ok`; без `-count=1` отдаётся кэш.
- 🔴 Проверять **ноль `FAIL`** (`go test … 2>&1 | grep -c '^--- FAIL\|^FAIL'` → `0`), не число `ok`.
- 🔴 Каждый новый тест обязан мочь упасть: шаг «саботаж» в задаче компилируется, применяется и
  читается целиком, затем откатывается.
- Правки — Edit/Write, не массовая замена скриптом (21.09 скрипт перевёл 12 файлов в CRLF).
- `gofmt -l` только своих файлов; `git add` конкретных файлов; коммиты без co-author.
- Коды ошибок наружу: существующие `NEEDS_TIME`, `INVALID_MODE`, `NOT_FOUND`, `CALENDAR_NOT_FOUND`
  плюс новые `REPEAT_CHOICE_REQUIRED`, `NOT_AN_OCCURRENCE`, `OCCURRENCE_REQUIRED`, `REPEAT_UNSUPPORTED`.

## Допущения, принятые в этом плане (сказать Денису в отчёте)

1. 🟡 **`SCHEDULED` остаётся только у быстрого пути.** `POST /api/tasks/{id}/schedule` по-прежнему
   ставит `status='SCHEDULED'` (веб на это рассчитывает, спека: «сигнатура для веба не меняется»,
   «SCHEDULED остаётся в данных»). `convert(mode=link)` статус **не трогает**. «Задача осталась в
   списке» после быстрой кнопки — это правка списка бота (показывать `TODO` и `SCHEDULED`), кусок A2.
2. 🟡 **`move` + `once` у задачи-серии** (решение Дениса 21.09: «переносится один день, серия
   остаётся») пишет этот день в `task_occurrence` состоянием `skipped` — третьего состояния нет,
   а новое потребовало бы миграции. Событие при этом **не связано** с задачей: это перенос.
3. 🟡 **Напоминания.** Настройка напоминаний — `task.reminder_offsets`; строки `reminder` — это журнал
   отправок. Событие получает **копию `reminder_offsets` задачи** во всех режимах (сейчас `convert`
   этого не делает, и событие с `{}` не напомнит никогда — gotcha из CLAUDE.md «Known Broken»).
   Журнал отправок переезжает в событие, **только когда уходит вся задача** (не `once`): при `once`
   серия продолжает жить, и её журнал остаётся с ней.
4. 🟡 **`link` + `once` у события-серии** отцепляет вхождение отдельным событием (тем же механизмом,
   что правка одного вхождения в вебе) и связывает с задачей **его**, а не всю серию.
5. 🟡 **Место события потеряно** при событие → задача (у задачи нет места) — в спеке его в таблице
   нет, но правило «потери названы» требует назвать; в `lost` идёт `location`.
6. Карточку задача → событие бот строит из полей задачи, которые у него уже есть; `dry_run` сделан
   только у событие → задача, где день и длительность считает сервер в зоне пользователя.

```go
func callTaskRoute(h http.HandlerFunc, path, taskID, userID string, body map[string]any) *httptest.ResponseRecorder {
	raw, _ := json.Marshal(body)
	req := httptest.NewRequest(http.MethodPost, path, bytes.NewReader(raw))

	rec := httptest.NewRecorder()
	h(rec, req.WithContext(ctx))
	return rec
```

```go
// rowQuerier is what both the pool and a transaction offer for one row.
type rowQuerier interface {
	QueryRow(ctx context.Context, sql string, args ...any) pgx.Row
}

// userZone is the zone the user lives in, for storing on what they create.
//
// 🔴 Until 21.09 every event made from a task was stamped 'Europe/Moscow'.
// The instant was still right — starts_at carries its offset — but the zone is
// what the recurrence expander keeps the local hour in, so a New York series
// slid by an hour at the first DST change after it was created.
func userZone(ctx context.Context, q rowQuerier, userID string) string {
	tz := "Europe/Moscow"
	_ = q.QueryRow(ctx,
		`SELECT COALESCE(timezone, 'Europe/Moscow') FROM "user" WHERE id = $1`, userID).Scan(&tz)
	return tz
}
```

**Поведение (таблица истины для реализации и тестов):**

| задача | `repeat` | `mode` | событие | задача после | журнал `reminder` |
|---|---|---|---|---|---|
| без `rrule` | игнор | link | разовое, `task_id` = задача | как была, **статус не тронут** | → событию |
| без `rrule` | игнор | move | разовое, `task_id` NULL | удалена | → событию |
| с `rrule` | пусто / чужое | любой | — | — | `400 REPEAT_CHOICE_REQUIRED` |
| с `rrule` | series | link | `rrule` = задачи | как была | → событию |
| с `rrule` | series | move | `rrule` = задачи | удалена | → событию |
| с `rrule` | once | link | разовое, `task_id` = задача | серия жива | **остаётся у задачи** |
| с `rrule` | once | move | разовое, `task_id` NULL | серия жива, день → `skipped` | **остаётся у задачи** |
| с `rrule` | once, день не в серии | любой | — | — | `400 NOT_AN_OCCURRENCE` |

Во всех строках событие получает `reminder_offsets` задачи, `description`, `tags`, `timezone` пользователя.
`rrule` задачи перед копированием проходит `recurrence.Parse`: строка до 18.09 может хранить правило,
которое API не развернёт → `400 REPEAT_UNSUPPORTED`, а не событие, которое «повторяется» один раз.

```go
var (
	ErrToTaskMode           = errors.New("mode must be move or link")
	ErrToTaskRepeatRequired = errors.New("repeat must be series or once for a repeating event")
	ErrOccurrenceRequired   = errors.New("once needs the day of the occurrence")
)

type ToTaskRequest struct {
	Mode       string `json:"mode"`
	Repeat     string `json:"repeat,omitempty"`
	Occurrence string `json:"occurrence,omitempty"`
	DryRun     bool   `json:"dry_run,omitempty"`
}

type ToTaskResult struct {
	Task    PlannedTaskWithID `json:"task"`
	Lost    []string          `json:"lost"`
	EventID *string           `json:"event_id"`
	DryRun  bool              `json:"dry_run"`
}

type PlannedTaskWithID struct {
	ID string `json:"id,omitempty"`
	PlannedTask
}

// EventToTask turns an event — a whole series, or one day of it — into a task.
func EventToTask(ctx context.Context, userID, rawID string, req ToTaskRequest) (*ToTaskResult, error) {
	if req.Mode != "move" && req.Mode != "link" {
		return nil, ErrToTaskMode
	}
	if req.Repeat != "" && req.Repeat != "series" && req.Repeat != "once" {
		return nil, ErrToTaskRepeatRequired
	}

	parentID, occDate, isInstance := parseInstanceID(rawID)
	parent, err := getEvent(ctx, userID, parentID)
	if err != nil {
		return nil, err
	}
	repeating := parent.Rrule != nil && *parent.Rrule != ""
	once := false
	if repeating {
		if req.Repeat == "" {
			return nil, ErrToTaskRepeatRequired
		}
		once = req.Repeat == "once"
		if !once {
			if _, perr := parseRRule(*parent.Rrule); perr != nil {
				return nil, errors.Join(ErrInvalidRrule, perr)
			}
		}
	}

	start, end := parent.StartsAt, parent.EndsAt
	if once {
		if !isInstance {
			if req.Occurrence == "" {
				return nil, ErrOccurrenceRequired
			}
			d, perr := time.Parse(instanceIDDateLayout, req.Occurrence)
			if perr != nil {
				return nil, ErrOccurrenceRequired
			}
			occDate = d
		}
		s, e, ok := occurrenceWindow(*parent, occDate)
		if !ok {
			return nil, errNoSuchOccurrence
		}
		start, end = s, e
	}

	tz := parent.Timezone
	var userTZ string
	if err := db.Pool.QueryRow(ctx,
		`SELECT COALESCE(timezone, 'Europe/Moscow') FROM "user" WHERE id = $1`, userID).Scan(&userTZ); err == nil {
		tz = userTZ // the reader's day, not the event's author's (learning-the-right-time-in-the-wrong-zone)
	}

	planned, lost := taskFromEvent(*parent, start, end, tz, repeating && !once)
	res := &ToTaskResult{Task: PlannedTaskWithID{PlannedTask: planned}, Lost: lost, DryRun: req.DryRun}
	if lost == nil {
		res.Lost = []string{}
	}
	if req.DryRun {
		return res, nil
	}

	calID, err := calendars.WritableIDFor(ctx, userID, parent.CalendarID)
	if err != nil {
		return nil, err
	}
	calIDs, err := calendars.WritableIDsFor(ctx, userID)
	if err != nil {
		return nil, err
	}

	tx, err := db.Pool.Begin(ctx)
	if err != nil {
		return nil, err
	}
	defer func() { _ = tx.Rollback(ctx) }()

	var anchor *time.Time
	if planned.Rrule != nil {
		a := planned.due
		anchor = &a
	}
	var taskID string
	if err := tx.QueryRow(ctx, `
		INSERT INTO task (user_id, calendar_id, title, description, status, priority,
		                  estimated_minutes, due_date, tags, contexts, reminder_offsets,
		                  rrule, repeat_anchor)
		VALUES ($1, $2, $3, $4, 'TODO', 3, $5, $6, $7, '{}', $8, $9, $10)
		RETURNING id::text`,
		userID, calID, planned.Title, planned.Description, planned.EstimatedMinutes,
		planned.due, planned.Tags, usersettings.DefaultTaskOffsets(ctx, userID),
		planned.Rrule, anchor).Scan(&taskID); err != nil {
		return nil, err
	}
	res.Task.ID = taskID

	switch {
	case once && req.Mode == "link":
		occ := *parent
		occ.StartsAt, occ.EndsAt, occ.Rrule = start, end, nil
		occ.TaskID = &taskID
		detached, derr := detachOccurrenceTx(ctx, tx, userID, occ, parentID, occDate)
		if derr != nil {
			return nil, derr
		}
		res.EventID = &detached.ID
	case once: // move: skip this one day, never the series
		if _, err := tx.Exec(ctx, `
			INSERT INTO event_exception (event_id, user_id, occurrence, skipped)
			VALUES ($1, $2, $3, true)
			ON CONFLICT (event_id, occurrence) DO UPDATE SET skipped = true, user_id = EXCLUDED.user_id`,
			parentID, userID, occDate); err != nil {
			return nil, err
		}
	case req.Mode == "link":
		if _, err := tx.Exec(ctx,
			`UPDATE event SET task_id = $2, updated_at = NOW() WHERE id = $1 AND calendar_id = ANY($3)`,
			parentID, taskID, calIDs); err != nil {
			return nil, err
		}
		res.EventID = &parentID
	default: // move
		if _, err := tx.Exec(ctx,
			`DELETE FROM event WHERE id = $1 AND calendar_id = ANY($2)`, parentID, calIDs); err != nil {
			return nil, err
		}
	}

	if err := tx.Commit(ctx); err != nil {
		return nil, err
	}
	return res, nil
}
```

```go
package events

import (
	"encoding/json"
	"errors"
	"net/http"

	"github.com/go-chi/chi/v5"
	"github.com/jackc/pgx/v5"

	"neuroboost/api-go/internal/calendars"
	"neuroboost/api-go/internal/middleware"
	"neuroboost/api-go/internal/util"
)

// ToTaskHandler handles POST /api/events/{id}/to-task.
func ToTaskHandler(w http.ResponseWriter, r *http.Request) {
	if db == nil {
		util.RespondError(w, http.StatusInternalServerError, "DB_NOT_INITIALIZED", "Database not initialized")
		return
	}
	userID := middleware.UserIDFromContext(r.Context())
	if userID == "" {
		util.RespondError(w, http.StatusUnauthorized, "NOT_AUTHENTICATED", "Not authenticated")
		return
	}
	id := chi.URLParam(r, "id")
	if id == "" {
		util.RespondError(w, http.StatusBadRequest, "MISSING_ID", "Event ID is required")
		return
	}
	var req ToTaskRequest
	if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
		util.RespondError(w, http.StatusBadRequest, "INVALID_REQUEST", "Invalid request body")
		return
	}

	res, err := EventToTask(r.Context(), userID, id, req)
	if err != nil {
		switch {
		case errors.Is(err, ErrToTaskMode):
			util.RespondError(w, http.StatusBadRequest, "INVALID_MODE", "Mode must be move or link")
		case errors.Is(err, ErrToTaskRepeatRequired):
			util.RespondError(w, http.StatusBadRequest, "REPEAT_CHOICE_REQUIRED", err.Error())
		case errors.Is(err, ErrOccurrenceRequired):
			util.RespondError(w, http.StatusBadRequest, "OCCURRENCE_REQUIRED", err.Error())
		case errors.Is(err, ErrInvalidRrule):
			util.RespondError(w, http.StatusBadRequest, "REPEAT_UNSUPPORTED", "The event's repeat rule cannot be copied")
		case errors.Is(err, pgx.ErrNoRows), errors.Is(err, errNoSuchOccurrence):
			util.RespondError(w, http.StatusNotFound, "NOT_FOUND", "No such event")
		case errors.Is(err, calendars.ErrCalendarNotFound):
			util.RespondError(w, http.StatusNotFound, "CALENDAR_NOT_FOUND", "Calendar not found")
		default:
			util.RespondError(w, http.StatusInternalServerError, "TO_TASK_ERROR", "Failed to turn the event into a task")
		}
		return
	}
	status := http.StatusCreated
	if res.DryRun {
		status = http.StatusOK
	}
	util.RespondJSON(w, status, res)
}
```
