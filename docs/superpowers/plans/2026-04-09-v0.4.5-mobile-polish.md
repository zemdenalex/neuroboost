### Task 2: Add Swipe Day Navigation on Mobile

**Files:**

- Modify: `web/src/components/Calendar/WeekGrid/WeekHeader.tsx`

Bug M3 (partial): Mobile shows 1 day with no way to switch between days.

- [ ] **Step 1: Add swipe detection to WeekGrid**

In `web/src/components/Calendar/WeekGrid/WeekGrid.tsx`, add touch swipe state and handlers. Find the state declarations (around line 29-32) and add:

```typescript
  const [swipeStartX, setSwipeStartX] = useState<number | null>(null);
```

Add swipe handlers after the existing useEffect blocks:

```typescript
  const handleSwipeStart = useCallback((e: React.TouchEvent) => {
    if (visibleDays >= 7) return; // Only swipe on mobile/tablet
    setSwipeStartX(e.touches[0].clientX);
  }, [visibleDays]);

  const handleSwipeEnd = useCallback((e: React.TouchEvent) => {
    if (swipeStartX === null || visibleDays >= 7) return;
    const dx = e.changedTouches[0].clientX - swipeStartX;
    const SWIPE_THRESHOLD = 50;
    if (Math.abs(dx) > SWIPE_THRESHOLD) {
      // Swipe left = next period, swipe right = previous period
      if (dx < 0 && onWeekChange) {
        onWeekChange(currentWeekOffset + 1);
      } else if (dx > 0 && onWeekChange) {
        onWeekChange(currentWeekOffset - 1);
      }
    }
    setSwipeStartX(null);
  }, [swipeStartX, visibleDays, currentWeekOffset, onWeekChange]);
```

- [ ] **Step 2: Attach swipe handlers to the grid container**

Find the scrollable container div that wraps the day columns (the `ref={scrollRef}` div). Add touch handlers to it:

```typescript
  onTouchStart={handleSwipeStart}
  onTouchEnd={handleSwipeEnd}
```

Note: These won't conflict with the existing DayColumn touch handlers because DayColumn touch handlers use `stopPropagation()` and require a long-press (500ms). A quick swipe will be handled by WeekGrid.
