# v0.4.7 New Pages & Tools — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build 5 features: Home dashboard (auth + landing), Planning page (weekly planning with backend), Reflections page (history + charts using existing API), Pomodoro timer (full-featured), Kanban board (customizable columns).

**Architecture:** Each feature is a standalone page. Home splits auth/unauth. Planning needs a new Go endpoint for weekly data. Reflections uses existing API. Pomodoro is pure frontend (localStorage). Kanban reuses Tasks API with drag-and-drop.

**Tech Stack:** Go 1.22 (backend), React 18, TypeScript, Tailwind CSS, i18next, Lucide React

### Task 2: Home Dashboard (Authenticated)

- [ ] **Step 1: Implement full dashboard**

The dashboard shows: Today's events (compact timeline), Task summary (due today, overdue, in progress), Quick action buttons, Week heatmap.

```tsx
import { useState, useEffect } from 'react'
import { Link } from 'react-router-dom'
import { useTranslation } from 'react-i18next'
import { Calendar, CheckSquare, Plus, Clock, TrendingUp } from 'lucide-react'
import { useAuthContext } from '../../contexts/AuthContext'
import { getEvents, getTasks } from '../../api'
import type { NbEvent, Task } from '../../types'

export function Dashboard() {
  const { t } = useTranslation('home')
  const { user } = useAuthContext()
  const tz = user?.timezone || 'Europe/Moscow'
  const [events, setEvents] = useState<NbEvent[]>([])
  const [tasks, setTasks] = useState<Task[]>([])

  useEffect(() => {
    const now = new Date()
    const todayStart = new Date(now.getFullYear(), now.getMonth(), now.getDate())
    const todayEnd = new Date(todayStart.getTime() + 86400000)
    getEvents(todayStart.toISOString(), todayEnd.toISOString()).then(setEvents).catch(() => {})
    getTasks().then(setTasks).catch(() => {})
  }, [])

  const todayEvents = events.sort((a, b) => a.startsAt.localeCompare(b.startsAt))
  const todoTasks = tasks.filter(t => t.status === 'TODO')
  const doneTasks = tasks.filter(t => t.status === 'DONE')
  const overdueTasks = todoTasks.filter(t => t.dueDate && new Date(t.dueDate) < new Date())

  return (
    <div className="p-6 max-w-5xl mx-auto space-y-6">
      {/* Greeting */}
      <div>
        <h1 className="text-2xl font-bold font-mono">
          {t('dashboard.greeting', { name: user?.displayName || user?.username || '' })}
        </h1>
        <p className="text-zinc-400 text-sm mt-1">{new Date().toLocaleDateString(undefined, { weekday: 'long', month: 'long', day: 'numeric' })}</p>
      </div>

      {/* Quick Actions */}
      <div className="flex gap-3">
        <Link to="/calendar" className="flex items-center gap-2 px-4 py-2 bg-blue-600/20 border border-blue-500/30 rounded-lg text-blue-400 hover:bg-blue-600/30 text-sm font-mono">
          <Plus className="w-4 h-4" /> {t('dashboard.newEvent')}
        </Link>
        <Link to="/tasks" className="flex items-center gap-2 px-4 py-2 bg-zinc-800 border border-zinc-700 rounded-lg text-zinc-300 hover:bg-zinc-700 text-sm font-mono">
          <Plus className="w-4 h-4" /> {t('dashboard.newTask')}
        </Link>
        <Link to="/tools/pomodoro" className="flex items-center gap-2 px-4 py-2 bg-zinc-800 border border-zinc-700 rounded-lg text-zinc-300 hover:bg-zinc-700 text-sm font-mono">
          <Clock className="w-4 h-4" /> {t('dashboard.pomodoro')}
        </Link>
      </div>

      <div className="grid md:grid-cols-2 gap-6">
        {/* Today's Schedule */}
        <div className="bg-zinc-900 border border-zinc-800 rounded-lg p-5">
          <div className="flex items-center gap-2 mb-4">
            <Calendar className="w-5 h-5 text-blue-400" />
            <h2 className="font-semibold font-mono">{t('dashboard.todaySchedule')}</h2>
            <span className="text-xs text-zinc-500 ml-auto">{todayEvents.length} {t('dashboard.events')}</span>
          </div>
          {todayEvents.length === 0 ? (
            <p className="text-zinc-500 text-sm">{t('dashboard.noEvents')}</p>
          ) : (
            <div className="space-y-2">
              {todayEvents.slice(0, 6).map(e => (
                <div key={e.id} className="flex items-center gap-3 text-sm">
                  <span className="text-zinc-500 w-12 shrink-0 font-mono">
                    {new Date(e.startsAt).toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' })}
                  </span>
                  <span className="text-zinc-200 truncate">{e.title}</span>
                </div>
              ))}
            </div>
          )}
        </div>

        {/* Task Summary */}
        <div className="bg-zinc-900 border border-zinc-800 rounded-lg p-5">
          <div className="flex items-center gap-2 mb-4">
            <CheckSquare className="w-5 h-5 text-green-400" />
            <h2 className="font-semibold font-mono">{t('dashboard.taskSummary')}</h2>
          </div>
          <div className="grid grid-cols-3 gap-4 text-center">
            <div>
              <div className="text-2xl font-bold text-blue-400">{todoTasks.length}</div>
              <div className="text-xs text-zinc-500">{t('dashboard.todo')}</div>
            </div>
            <div>
              <div className="text-2xl font-bold text-green-400">{doneTasks.length}</div>
              <div className="text-xs text-zinc-500">{t('dashboard.done')}</div>
            </div>
            <div>
              <div className="text-2xl font-bold text-red-400">{overdueTasks.length}</div>
              <div className="text-xs text-zinc-500">{t('dashboard.overdue')}</div>
            </div>
          </div>
        </div>
      </div>
    </div>
  )
}
```

- [ ] **Step 1: Implement Go planning endpoint**

Read the current `api-go/internal/planning/handlers.go` (currently returns 501). Replace with a real handler that aggregates data from events and tasks tables.

`GET /api/planning/week?date=2026-04-07` returns:
```json
{
  "data": {
    "week_start": "2026-04-07T00:00:00Z",
    "unscheduled_tasks": [...],
    "week_events": [...],
    "scheduled_hours": 32.5,
    "available_hours": 40
  }
}
```

The handler queries:
- Tasks with status != 'DONE' and no scheduled event → unscheduled
- Events in the date range → week_events
- Sum event durations → scheduled_hours
- Work hours from user settings → available_hours
