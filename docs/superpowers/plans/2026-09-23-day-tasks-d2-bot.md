# «Задачи дня» D2 — бот: план

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Шаги — `- [ ]`.
> План короткий по просьбе Дениса («needs a short plan first»): интерфейсы, callback'и, тексты
> и тест на каждую задачу; код пишется test-first в ходе сборки.

**Goal:** в боте появляется экран «📌 Задачи дня», кнопка «📌 В задачи дня» на карточке задачи
и настройка «🎯 Задач в день» — поверх готового API D1.

**Architecture:** тонкий клиент `api/daytasks.go` к ручкам D1; экран рисуется чистыми
функциями (`renderDay…`), хэндлер только ходит в API и выбирает, что нарисовать. Все callback'и
на одном префиксе `dt_`, маршрутизируются одной функцией `handleDayTasksCallback` (как `qa_`/`qs_`).
Уровень и счёт «сделано» бот **не считает** — берёт `level`/`done` из ответа (спека §3).

**Tech Stack:** Go, go-telegram-bot-api v5, модуль `bot/`.

**Spec:** `docs/superpowers/specs/2026-09-22-day-tasks-design.md` §4, §5, §8, §10 (срез D2).

## Global Constraints

- Уровни `0…5` = ⬛🟫🟥🟧🟨🟩 — из поля `level` ответа; бот не пересчитывает.
- День — дата **в зоне пользователя** (`h.location(chatID)`), формат `YYYY-MM-DD`.
- Убрать — до 12:00 сегодня (сервер: `409 TOO_LATE`), прошлый день — только чтение.
- Цель N — `settings.day_tasks_target` (верхний уровень), 3–7, запись через `PatchSettings`
  (читает, сливает, пишет — gotcha 21). Взятый день хранит свою цель (решение Дениса 23.09).
- Тексты пользователю — без длинных тире и жаргона (правило client-texts), RU и EN через `h.t`.
- Названия дней недели — свои (`weekdayName`), не Go-шные (они английские в любом языке).
- Каждый экран с кнопками — с `ℹ️ Что это?` (`HelpButton`, скан `help_scan_test` требует).
- callback_data ≤ 64 байт: самый длинный `dt_put_2026-09-23_<uuid36>` = 54.
- Экраны из callback'а — `editOrSend` на том же сообщении (скан `inplace_test`).
- Не пушить `develop` без слова Дениса; dev-бот — `scripts/deploy-dev-bot.sh` после push.

## Review Focus

1. Кнопка на старом сообщении (вчерашний экран, задача удалена) → понятная фраза, не «что-то пошло не так».
2. День не взят, набор пуст (нет открытых задач) → экран говорит, что взять нечего, «✅ Беру» не рисуется.
3. Серия в наборе: ✅ на сегодняшнем экране закрывает **сегодняшний** день серии (`MarkOccurrence`), а не «следующий».
4. `NOT_AN_OCCURRENCE` из day-tasks значит «в этот день серия не повторяется», а в `errorText` тот же код значит «серия закончилась» — перевод свой, до общего.
5. Длинное название задачи в кнопке — обрезается (`shorten`), кнопка не ломает ряд.

## Экраны и callback'и

| Callback | Что делает |
|---|---|
| `dt_d_today` / `dt_d_<day>` | экран дня (из меню — `today`) |
| `dt_ok_<id>` | ✅ задачу (только на сегодняшнем экране), перерисовать сегодня |
| `dt_take_<day>` | взять день **предложением** (перечитывает `/proposal` в момент нажатия) |
| `dt_edit_<day>` | экран «Поменять»: набор с ❌, ➕, для невзятого — «✅ Беру этот набор» |
| `dt_takeset_<day>` | взять день **текущим набором** |
| `dt_rm_<day>_<id>` | убрать из набора |
| `dt_add_<day>` | список открытых задач, которых нет в наборе (до 8, по приоритету) |
| `dt_put_<day>_<id>` | добавить в набор, вернуться в «Поменять» |
| `dt_pin_<id>` | с карточки задачи: выбрать день — сегодня · завтра · ✏️ дата |
| `dt_pdt_<id>` | ✏️ дата: текстовый шаг `day_task_date` (FlowData `task`), дата — `parse.ParseLine(...).Draft.Day`/`HasDay`; прошлое или непонятое — переспросить |
| `dt_pd_<day>_<id>` | добавить на этот день, ответ с кнопками «📌 Задачи дня» и «« К задаче» |
| `settings_dtn` / `dtn_<n>` | настройка N, 3…7 |

**Решения Дениса 23.09:** нажатие ⬜ на сегодняшнем экране **отмечает сделанным** (✅ → карточка);
невзятый день — **«✅ Беру» или «✏️ Выбрать самому»**; день на карточке — **сегодня · завтра · ✏️ дата**.

**Экран дня** (`renderDayScreen`):

```
📌 Задачи дня · ср 23.09
🟧 3 из 5

✅ купить молоко
✅ позвонить маме
⬜ отчёт
```

- Взятый день: кнопки задач (сегодня: ⬜ → `dt_ok_`, ✅ → карточка `task_action_`; другой день —
  все на карточку), `✏️ Поменять` (если день не прошёл), `◀ ▶`, `ℹ️`, `« Меню`.
- Невзятый сегодня/будущий: показывает **предложение**, текст «День ещё не взят. Беру этот набор?»,
  кнопки `✅ Беру` · `✏️ Выбрать самому` (→ «Поменять»), `◀ ▶`, `ℹ️`.
- Прошедший невзятый: «⬛ День не был взят», только `◀ ▶`.
