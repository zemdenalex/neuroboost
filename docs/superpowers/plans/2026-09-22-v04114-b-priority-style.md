# 11.4 · B — символ приоритета · план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** приоритет рисуется одним из трёх стилей (`circles` по умолчанию · `dot` · `dash`), стиль
выбирается в ⚙️ Настройках, на онбординге и одноразовым вопросом у тех, кто онбординг уже прошёл.

**Spec:** `docs/superpowers/specs/2026-09-21-v04114-bot-design.md` §B.

## Устройство

- `format.Priority(style string, p int) string` — **одна** функция отрисовки. `circles` — как
  `PriorityEmoji`; `dot` — `●1` `●2` `○3` `○4` `○5` `·0`; `dash` — `—`. Неизвестный стиль = `circles`.
- Стиль — ключ `settings.bot.priority_style`, запись `SetBotSetting` (S3 статистики). Кэш в сессии
  (`state.Session.PriorityStyle` + `PriorityStyleKnown`), как язык: иначе каждый экран списка —
  лишний запрос `GET /api/auth/me`.
- `h.prio(chatID, p)` — то, что зовут обработчики. Чистые функции получают стиль параметром:
  `taskCardTextFull(…, style)`, `wizardStepText(…, style)`.
- 🔴 Скан-тест: ни один файл `handlers/` (кроме `prio.go`) не зовёт `format.PriorityEmoji`.
- `dash`: карточка задачи называет приоритет словом — `Приоритет: срочно` (спека §B1).
- ⚠ Не входит: кнопки выбора приоритета в мастере (`keyboards/task.go`) — там символ стоит рядом
  со словом («🔴 срочно»), и стиль туда не протянут; записать Денису.

## Где выбирается — один экран, три входа

`keyboards.PriorityStyle(lang, current, prefix, backData, backLabel)` — три кнопки с превью строки:
`🔴 🟠 🟡  кружки` · `●1 ●2 ○3  точки` · `— — —  тире`, `✓` у текущего.

| Вход | Префикс | Назад |
|---|---|---|
| ⚙️ Настройки → `🔘 Символ приоритета` (`settings_prio`) | `prs_` | `« Настройки` → `settings_menu` |
| Онбординг: пояс → **символ** → шкала → финал | `ob_pr_` | `Дальше →` → `ob_scale` |
| Одноразовый вопрос при открытии меню | `prq_` | `« Меню` → `main_menu` |

Одноразовый вопрос: онбординг пройден, ключа `priority_style` нет, ключа `priority_style_asked` нет
→ перед меню показать экран и записать `priority_style_asked=1` (вопрос «один раз» — даже если
пользователь ушёл, не выбрав).

## Тесты (каждый с саботажем)

1. `format.Priority` — три стиля, неизвестный = кружки.
2. Скан: `PriorityEmoji` вне `prio.go` в `handlers/` → `FAIL` (саботаж: вернуть прямой вызов в `today.go`).
3. Стиль из настроек меняет список задач: `dot` → строка начинается с `●1`.
4. `prs_dash` пишет `"priority_style":"dash"`, язык цел; неизвестный стиль не пишет ничего.
5. Онбординг: пояс → `ob_prio`; `ob_pr_dot` пишет; «Дальше» ведёт на `ob_scale`.
6. Одноразовый вопрос: первый вход в меню — экран вопроса и `priority_style_asked`; второй — меню.
7. Карточка задачи в `dash` называет приоритет словом.
