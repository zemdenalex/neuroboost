# v0.4.4 Calendar UX Fix — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the calendar interaction model so click=select, double-click=edit, drag=move, handle-drag=resize. Fix task scheduling, performance, and i18n bugs.

**Architecture:** All changes are in the frontend WeekGrid component tree. The core fix is in DayColumn.tsx where mousedown events incorrectly route to resize instead of move. We add a drag threshold (5px) to distinguish click from drag, separate the action types, and fix the drag handlers accordingly.

**Tech Stack:** React 18, TypeScript, Tailwind CSS, i18next

### Task 1: Fix DayColumn.tsx — Separate Click from Drag

**Files:**
- Modify: `web/src/components/Calendar/WeekGrid/DayColumn.tsx:76-110`

The root cause of bugs C1, C2, C3: `handleEventMouseDown` immediately calls `onDragStart` on mousedown. Line 104 sends `'resize-start'` for both top AND bottom handles. Line 107 sends `'resize-end'` instead of `'move'` for body drag. There's no drag threshold, so a simple click triggers drag behavior.

Replace lines 76-110 in `web/src/components/Calendar/WeekGrid/DayColumn.tsx`:

    const track = ev.currentTarget.parentElement;
    const rect = track!.getBoundingClientRect();
    const eventRect = ev.currentTarget.getBoundingClientRect();
    const yInEvent = ev.clientY - eventRect.top;
    const isTopHandle = yInEvent < 8;
    const isBottomHandle = yInEvent > eventRect.height - 8;
    
    const isMultiDaySegment = event.span && event.span.spanDays > 1;
    
    // Set drag meta
    dragMeta.current = {
      colTop: rect.top,
      scrollStart: scrollContainer.current?.scrollTop ?? 0
    };
    
    // Determine start/end minutes
    const startMin = utcToLocalMinutes(event.startsAt, timezone);
    const endMin = utcToLocalMinutes(event.endsAt, timezone);
    
    // Resize handles: top = resize-start, bottom = resize-end (single-day only)
    if (isTopHandle && !isMultiDaySegment) {
      ev.preventDefault();
      ev.stopPropagation();
      onDragStart(day, startMin, 'resize-start', event.id, event);
    } else if (isBottomHandle && !isMultiDaySegment) {
      ev.preventDefault();
      ev.stopPropagation();
      onDragStart(day, startMin, 'resize-end', event.id, event);

    ev.stopPropagation();

      // Drag threshold: 5px before activating move
      if (drag && drag.kind === 'move' && drag.pending) {
        const startX = drag.startX ?? ev.clientX;
        const startY = drag.startY ?? ev.clientY;
        // Store initial mouse position on first move event
        if (drag.startX === undefined) {

        setDrag(prev => prev && prev.kind === 'move' ? { ...prev, pending: false } : prev);
      }
