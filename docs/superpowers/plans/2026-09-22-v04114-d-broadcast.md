# 11.4 · D — отписка и рассылка · план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** рассылка «что нового» — команда бота для админа с пробным прогоном и результатом по
каждому получателю; повтор шлёт только тем, кому не дошло; у каждого — кнопка отписки.

**Spec:** `docs/superpowers/specs/2026-09-21-v04114-bot-design.md` §D.

## Решение плана — журнал без миграции 🟡

Спека просит «журнал по хэшу id», 11.4 обещан без миграций. Журнал — **в настройках самого
получателя**: `settings.bot.broadcasts.<version> = "<код>"`, пишет его API по сервисному токену.
Получатели выбираются запросом, который **пропускает `200` и `403`** (спека D2: 403 = «бот
заблокирован», повтор бесполезен). Хэш id — только в логе бота: сам id не печатается нигде.

## API (`api-go/internal/broadcast`, новый пакет; роуты в группе `/api/svc`)

- `GET /api/svc/broadcast/recipients?version=v0.4.11.4&active_days=10` →
  `[{"tg_id": 123, "lang": "ru"}]`: `tg_id IS NOT NULL`, `tg_auth_date > now() - days`,
  `settings.bot.updates` ≠ `"off"`, `settings.bot.broadcasts.<version>` ∉ {`"200"`, `"403"`}.
  `active_days` 1…90, `version` непустая и ≤ 32 знаков, иначе 400.
- `POST /api/svc/broadcast/mark {"tg_id", "version", "code"}` → `jsonb_set` по пути
  `{bot,broadcasts,<version>}` с созданием недостающих уровней; остальной blob цел.
- Тесты против БД через обработчики: отписавшийся не в списке; вернувший подписку — в списке;
  помеченный `200` и `403` не в списке, `0` (сеть) — в списке; неактивный 11 дней — не в списке;
  `mark` не трогает `lang` и прочие ключи.

## Бот

- Клиент: `BroadcastRecipients(svcToken, version, days)`, `MarkBroadcast(svcToken, tgID, version, code)`,
  `IsAdmin(token)`.
- `/broadcast` — только если `is_admin`; иначе ответ «Команда недоступна» и **ничего** не
  запрашивается у сервиса. Пробный прогон: версия и дата из `release.Latest()`, получатели по
  языкам, оба текста, кнопки `📣 Отправить N` (`bc_go_<version>`) · `❌ Отмена` (`bc_x`).
- `bc_go_`: снова проверка админа и версии (кнопка из старого сообщения не шлёт чужую версию),
  получатели заново, отправка по одному: текст на языке получателя + кнопка
  `🔕 Не присылать обновления` (`upd_off`). Код: `200` — дошло; `tgbotapi.Error.Code` — если есть;
  иначе `0` (сеть). `MarkBroadcast` для каждого. Лог: `broadcast <version> <sha256(id)[:8]> <code>`.
  Итог админу: «дошло X · заблокировали бота Y · не дошло Z — повтор пошлёт только им».
- `upd_off` / `upd_on` — ключ `settings.bot.updates` = `off`/`on`; экран с состоянием и кнопкой
  обратного действия. ⚙️ Настройки → `🔔 Обновления` (`settings_updates`) — тот же экран.
- Тесты: не-админ ничего не запрашивает и не шлёт; пробный прогон не шлёт ни одному получателю;
  отправка: получатель с 403 помечен `403`, успешный — `200`; в ответе админу и в логе нет ни
  одного `tg_id`; `upd_off` пишет `"updates":"off"`, язык цел.
