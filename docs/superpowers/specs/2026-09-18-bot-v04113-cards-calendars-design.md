## 1. Карточка называет всё

### Почему это не косметика

Сейчас `handlers/card.go` рисует поле **только когда оно заполнено**: `case st.D.Repeat != ""`
(строка 264) и так далее. Человек, который ни разу не написал «каждую неделю», не знает, что
повтор вообще бывает. То же с тегами, цветом, календарём, заметкой. Это и есть корень второго
замечания Дениса — «разница между задачами и событиями не до конца понятна»: карточка не
показывает, чем они отличаются, потому что показывает только то, что ты сам назвал.

### Вид

```
📅 Стоматолог
🗓 Дата:      19.09
🕐 Время:     15:00–16:00
🔁 Повтор:    нет
📁 Календарь: Личный
🔔 Напомнить: за час
🏷 Теги:      нет
🎨 Цвет:      нет
📝 Заметка:   нет
```

- Порядок полей **постоянный** и не зависит от того, что заполнено: глаз запоминает место.
- Пустое — это слово `нет` (`none` в en), а не пропуск и не прочерк.
- ⚠ Неопределённость (`IsUncertain`) и «спрошу» из v0.4.11.2 остаются как есть — они сильнее
  «нет» и печатаются вместо него.
- У задачи вместо «Время» — «Срок»; остальное то же, **включая «Календарь»**. Строка
  «✅ и задача — её можно отметить выполненной» остаётся.
  ⚠ Первая редакция этой спеки утверждала, что у задач календаря нет. Это неверно:
  `000012_calendars.up.sql:31,67` добавляет `task.calendar_id` и делает его `NOT NULL`. Заодно
  это закрывает третье замечание приёмки 11.09 — «"общая" задача ничем не отмечена»: строка
  «📁 Календарь: Работа» и есть отметка.

### Где именно применяется

🔴 Называем поимённо, иначе это расползётся на уведомления и списки:

| Поверхность | Полный список полей | Файл |
|---|---|---|
| Карточка подтверждения при создании | 🟢 да | `handlers/card.go` `showCard` |
| Карточка существующего события | 🟢 да | `handlers/eventedit.go` `handleEventCard` |
| Карточка задачи | 🟢 да | `handlers/tasks.go` |
| Строка в списке событий/задач | 🔴 нет — одна строка | `handlers/agenda.go`, `tasklist.go` |
| Текст напоминания | 🔴 нет | `api-go` (и не наш релиз) |

### Проверка

- Тест: у драфта без единого необязательного поля карточка содержит **все девять** ярлыков.
  Красным он показывается сам — сегодняшний код печатает 4 строки из 9.
- Тест: заполненное поле печатает значение, а не «нет» (иначе первый тест пройдёт на карточке,
  где всё — «нет»).
- Скан i18n: ни одного нового голого литерала, все ярлыки через `i18n.T`.

## 2. Календари в боте

### Экран

```
📁 Календари

📁 Личный · 41 событие
📁 Работа · 12 · 2 участника
📁 Семья · 3 · чужой, владелец @denis

[➕ Создать] [⬅️ Назад]
```

Нажатие на календарь → карточка:

```
📁 Работа
🎨 Цвет:      #7c3aed
👥 Участники: 2
🔑 Роль:      владелец

[✏️ Имя] [🎨 Цвет]
[👥 Участники] [🔗 Пригласить]
[🗑 Удалить]
```

- Для чужого календаря вместо «Удалить» — «🚪 Выйти», а «Имя/Цвет/Пригласить» не показываются
  (роль не владелец). Владельцу «Выйти» не предлагается вовсе — API вернёт `ErrCannotRemoveOwner`,
  и лучше не рисовать кнопку, чем ловить ошибку (кнопка — заявка, обработчик — свидетельство).
- Личный календарь: удалить нельзя (`idx_calendar_one_personal_per_owner` — он один и он нужен).
- 🔴 Удаление и выход — с подтверждением одной кнопкой «Да, удалить «Работа»», не голым «Да».

### Приглашение — оба пути на одном экране

```
🔗 Пригласить в «Работа»

[🔗 Ссылкой] [✉️ По email]
```

- **Ссылкой** → `POST /api/calendars/{id}/invite-links {role}` → бот присылает **готовое
  сообщение для пересылки**:

  ```
  Зову тебя в календарь «Работа» в NeuroBoost.
  Открой: https://t.me/NeuroBoost_assistant_bot?start=inv_<token>
  ```

  Одно сообщение, которое пересылается как есть — это и есть путь для человека без email
  (Настя). `start=inv_<token>` ловится в `handlers/commands.go` и ведёт на вопрос «Принять
  приглашение в «Работа»?» **до** онбординга, если человек новый: онбординг после ответа.
- **По email** → текстовый шаг → `POST /api/calendars/{id}/invites {email, role}`. Ответ 404
  «нет такого пользователя» показывается человеческим текстом с предложением дать ссылку.
- Роль по умолчанию — та же, что в вебе; выбор роли кнопками не добавляем (меньше шагов).

### Где живёт вход

В главном меню рядом с «🗓 Календарь». ⚠ Не в настройках: настройки — это то, куда новичок
не заходит, ровно по этой причине 17.09 не нашли язык.

### Проверка

- Fake API: список · создание · переименование · цвет · приглашение ссылкой · приглашение по
  email · участники · выход · удаление.
- Тест: для чужого календаря кнопок «Имя/Цвет/Удалить» нет, есть «Выйти».
- Тест: для личного календаря нет ни «Удалить», ни «Выйти».
- Тест: `start=inv_<token>` у **нового** пользователя сначала спрашивает про приглашение,
  потом запускает онбординг.
- 🔴 Ни одной пустой клавиатуры — существующий скан ловит это сам.

## 3. Отложить напоминание кнопками

Сегодня: `notifier/callback.go:107,126` — ровно одна кнопка «⏰ +10 мин». Денис просит выбор.

```
🔔 15:00 Стоматолог
[✅ Готово] [⏰ 10 мин] [⏰ Час]
```

- Обе кнопки зовут тот же `POST /api/svc/notifications/{id}/action {action:"snooze", minutes}`
  — 10 и 60. Потолок API — сутки, обе внутри.
- 🔴 `callback_data` ≤ 64 байт: минуты кодируются в код действия (`codeSnooze10`, `codeSnooze60`),
  а не дописываются в payload. `KeyboardFits` проверяет настоящие кнопки — тест на это уже есть
  и его надо расширить на новую клавиатуру.
- ⚠ Тексты кнопок остаются русскими — **это известный дефект и он чинится в v0.4.11.4**
  (пункт 11). Здесь не трогаем, чтобы не тащить `api-go`.

## 4. Сообщить об ошибке · предложить улучшение

```
⚙️ Настройки → 💬 Обратная связь
[🐞 Ошибка] [💡 Идея]
→ «Опиши в одном сообщении, я передам»
→ POST /api/feedback {type, title, description, page_url:"bot", user_agent:"telegram"}
→ «Спасибо, записал. Это #128.»
```

- `type` — `bug` / `feature`, как в вебе (`web/src/components/FeedbackButton/`).
- `title` — первые ~60 символов сообщения, `description` — всё сообщение. Отдельный вопрос
  «а теперь заголовок» не задаём (меньше шагов).
- Эндпоинт **публичный** (`main.go:103`), JWT не нужен — но `user_id` подставляем, когда он
  есть, иначе обращение не с кем связать.

## 5. Что нового

```
⚙️ Настройки → 🆕 Что нового
→ текст последнего релиза + [📜 Прошлые версии]
```

- Текст лежит **в коде бота** (`internal/release/notes.go`), а не тянется из `docs/relizy/` —
  бот не имеет доступа к репозиторию, и файл, который надо не забыть скопировать при деплое,
  будет забыт.
- Две–три строки на версию, языками ru/en, без списка коммитов.
- 🔴 Тест: у самой свежей версии в списке текст есть на обоих языках. Иначе «что нового» будет
  пустым ровно в том релизе, ради которого его добавили.
