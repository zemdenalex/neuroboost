## 1. One-pager (для анкет, писем, формы Angelsdeck)

**NeuroBoost** — календарь-первым планировщик для людей, которым трудно держать день в голове:
рассеянное внимание, «слепота ко времени», много начатого. Календарь — источник правды, задачи
существуют, чтобы их поставить во время и потом оглянуться. Работает в браузере и в Telegram-боте,
с общим аккаунтом; скоро — Telegram Mini App (тот же календарь внутри Telegram, без логина).

**Проблема.** Обычные таск-менеджеры собирают бесконечные списки. Человеку с рассеянным вниманием
список не помогает: ему нужно видеть, *когда* он что делает, и получать напоминание в том месте, где он
уже живёт (мессенджер), а не в ещё одном приложении.

**Что делает NeuroBoost.**
- Календарь недели/месяца с перетаскиванием; задача превращается в событие в один жест
- **Задачи дня** (механика по мотивам календаря Atrioc): 3–7 дел на день, день красится по выполненному (🟩 всё · 🟧 почти · 🟥 немного · ⬛ ничего) — видимая полоса успехов без стыда за пропуски
- Бот в Telegram: запись задачи и события одной строкой («Ужин завтра 19:00»), напоминания, «Сегодня», месячный календарь, подзадачи
- Рефлексия по событию (фокус / энергия / настроение), недельное планирование с загрузкой по часам

**Кому.** Взрослые, которым трудна самоорганизация: студенты, фрилансеры, люди с нейроотличностью
(без медицинских заявлений). Вход — через Telegram: там уже живут и там приходят напоминания.

**Стадия.** Работающий продукт в проде (neuroboost.website, @NeuroBoost_assistant_bot), 8 релизов
за 3 месяца, первые внешние пользователи с 16.09.2026. Выручки нет. Основатель один (ИП).

**Что просим.** Гранты, акселерацию без доли, призовые, спонсорство. Права на код и долю не отдаём.

## 3. Питч-дек — 10 слайдов (структура; колода — после выбора программы)

1. **NeuroBoost** — «Календарь, который помнит за тебя» · сайт, бот, контакт
2. **Проблема** — списки задач не работают для рассеянного внимания; время невидимо; напоминания приходят не туда
3. **Решение** — календарь как источник правды + задачи дня + бот в Telegram (скриншоты: неделя, месяц «Только задачи дня», бот «📅 Сегодня»)
4. **Как это выглядит** — 3 экрана: веб-календарь, задачи дня с цветом, бот
5. **Почему сейчас / почему Telegram** — пользователи уже там; Mini App даёт календарь без установки
6. **Стадия и что сделано** — таблица §2: 8 релизов за 5 недель, ~1700 автотестов, ручная приёмка
7. **Первые пользователи** — честные цифры §2 + цитаты тестеров (из `ref/feedback/bot-pervye-testery-2026-09-16-17.md`, только с их согласия)
8. **Модель** — freemium: бесплатно календарь и бот; платно — 🟡 **не решено Денисом** (варианты: подписка на синхронизации/ИИ-разбор, командные календари)
9. **Команда** — основатель: полный стек (Go, React, Telegram), продукт с нуля; 🟡 нужен текст от Дениса
10. **Что просим** — грант / акселерация без доли; на что пойдут деньги: 🟡 **нужны цифры от Дениса**
