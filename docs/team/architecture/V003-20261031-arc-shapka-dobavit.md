# Телефон: шапка календаря, «Добавить», «Месяц» — спека (31.10.2026)

Страница вариантов: `docs/team/architecture/V003-20261027-var-shapka-dobavit-mesyats.html`.
Чек-лист: `docs/tasks-shapka-dobavit.md`. Аудит трения: `docs/team/research/V003-20261026-res-audit-treniya.md` №1, №7, №9.

## 1. Зачем

Аудит трения 26.10: на телефоне сетка времени начинается на 283 px (в приложении 298) — две строки кнопок,
подсказка в две строки, «весь день» карточкой; «Добавить» — меню «Событие / Задача» и форма; «Месяц» открывает
полосу недели, а не месяц.

## 2. Выбрано (Денис, 31.10, дословно)

> «header A + C choice in settings, for creation I think it should have simple mode and elaborate, and simple uses A,
> elaborate opens like the one in ticktick, month b and c depending on what is the choice of header»

| Шапка (настройка) | Что на экране | «Месяц» |
|---|---|---|
| **A — одна строка** | ← → дата «Сег.» Н/М слои — одной строкой; «+ Задача» на телефоне убрана (есть «+» внизу); подсказка в одну строку | **C** — кнопка «Месяц» всегда открывает настоящий месяц (вариант месяца телефона: сетка+список или тепловая) |
| **C — полоса недели** | 7 дней с полосками занятости — навигация; заголовок «Октябрь ▾»; переключателя Неделя/Месяц нет | **B** — тап по «Октябрь ▾» раскрывает месяц; тап по дню — назад в день |

«Добавить» (кнопка «+» в нижней панели), настройка режима:
- **простой = A**: одна строка, под ней превью разбора («завтра 10 врач» → событие завтра 10:00); есть время → событие,
  нет → задача; ссылка «подробно…» открывает подробный режим с уже набранным текстом.
- **подробный — как в TickTick** (скрины `ref/konkurenty-skriny-2026-10-26/photo_10, 13, 14`): лист снизу —
  название, описание, ряд чипов: дата (заполнена выбранным днём), время/длительность, приоритет, календарь, «⋯»
  (сделать событием/задачей, полная форма).

## 3. Не входит

- Десктоп и планшет (≥768 px) — без изменений.
- «Весь день» строкой с чипами — отдельным шагом, если останется место после шапки (сейчас полоса уже тонкая, 25.09).
- Голосовой ввод, шаблоны, картинки из меню TickTick.
- Бот.

## 4. Готово, когда

- На 375×667 в шапке A сетка времени начинается не ниже ~190 px (замер e2e по `getBoundingClientRect`).
- Переключение шапки в ⚙️ меняет телефон без перезагрузки; на десктопе ничего не меняется.
- В шапке A «Месяц» открывает сетку месяца; в шапке C кнопки «Месяц» нет, тап по заголовку раскрывает месяц.
- «+» → строка «завтра 10 врач» → Enter создаёт событие на завтра 10:00 (утверждение по API, тестовый префикс, удаление).
- Строка без времени создаёт задачу.
- Подробный режим: дата-чип заполнен днём, открытым в календаре; создание проходит через те же API.
- Каждый e2e с саботажем, который краснеет.

## 5. Решения

- Вкус — Денис (цитата выше).
- Технические, обратимые (принял агент → `ratify`):
  - ключи настроек верхнего уровня `phone_header_variant` (`row` | `strip`) и `add_mode` (`simple` | `detailed`) —
    как `header_variant`: `createSettingsSaver` сливает неглубоко;
  - по умолчанию шапка `row` у всех (A первой в его ответе и рекомендована; C — одно нажатие в ⚙️). Перенос
    `phone_month_variant = strip` → шапка C отклонён: e2e-аккаунт — его настоящий, с `strip`, и все мобильные спеки
    молча уехали бы в C. e2e задают шапку перехватом ответа `GET /api/auth/me`, в настройки не пишут;
    режим «Добавить» по умолчанию `simple`;
  - в шапке C телефон всегда в виде дня (сохранённый `month` на телефоне не действует), месяц по заголовку —
    временное состояние, не `saveCalendarView`;
  - открытый в календаре день — в маленьком контексте, чтобы «+» из нижней панели знал его;
  - `phone_month_variant = strip` дальше читается как `split` для месяца (полоса переехала в шапку).
- Подробный режим — вкусовой экран: до реализации кликабельный прототип на странице вариантов (правило
  `variants-must-be-clickable`), реализация — после того как Денис его потрогает.
