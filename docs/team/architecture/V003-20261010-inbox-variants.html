NeuroBoost Inbox — заметки, идеи, фидбэк из Telegram

Денис, 10.10: «simple bot without ai that stores notes, ideas and feedback from telegram with tags … so when I have time, we can go through together, without wasting tokens or intellect» · «I would love for it to be in neuroboost actually, just for me».
Его ответы: #теги в тексте, без тега — кнопки (тип idea / link / feedback / reflection / note + проект), без тега вообще → inbox · текст, ссылки, пересылки с источником, фото, голос (без расшифровки) · статус new → discussed → done / dropped · без LLM.

Что уже есть в коде: флаг is_admin у пользователя (api-go/internal/admin) — им и закрываем «только для меня»; режимы бота — CurrentFlow в bot/internal/handlers/flows.go. 🔴 Главное ограничение: сейчас любой свободный текст в боте становится задачей/событием (quick add), а фото и голос бот не принимает вовсе. Значит вопрос — как отличить «запиши в inbox» от «создай задачу».

A — рекомендую

Режим «📥 Inbox» в основном боте

Меню (только is_admin): [📥 Inbox]
 ├ «Режим записи: вкл» — всё входящее → заметка
 │   текст / ссылка / пересылка / фото / голос
 │   #idea #avocar → сохранено ✅  (id 142)
 │   без тегов → [idea][link][feedback][reflection][note]
 │               [avocar][archifex][harness][graph][—]
 │               (не нажал → inbox)
 ├ «Выйти» → бот снова создаёт задачи
 └ Списки: new по типу / проекту, сменить статус
  • Один бот, один токен, деплой как обычно (dev-скрипт, прод — по «да»)
  • ⚠ Надо помнить, в каком режиме бот; режим живёт в памяти бота — после рестарта сбрасывается в обычный (безопасно: худшее — задача вместо заметки)
